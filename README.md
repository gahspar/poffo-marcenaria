# Poffo Marcenaria — site modelo

Site institucional premium para apresentação comercial da Poffo Marcenaria, desenvolvido em Next.js, TypeScript e CSS responsivo.

## Plano estratégico aplicado

1. **Posicionamento:** apresentar a Poffo como marcenaria sob medida de linguagem contemporânea, com atuação em Blumenau e experiência desde 2015.
2. **Primeira impressão:** hero de alto impacto com tipografia arquitetônica, imagem original e linguagem visual própria em preto, branco e azul-cobalto.
3. **Prova visual:** um projeto real contado em cinco capítulos durante a rolagem, seguido por um portfólio de ambientes complementares.
4. **Clareza comercial:** explicar diferenciais e processo sem criar depoimentos, métricas ou promessas não verificadas.
5. **Conversão:** CTAs para WhatsApp, Instagram, localização e formulário que prepara uma mensagem personalizada.
6. **Confiança técnica:** SEO local, dados estruturados, acessibilidade, redução de movimento, responsividade e Vercel Analytics.

## Experiência e recursos

- cabeçalho adaptativo e menu mobile de tela cheia;
- hero cinematográfica com revelação, movimento de câmera e feixe de luz;
- narrativa de projeto com imagens fixas e transições de cortina guiadas pela rolagem;
- portfólio editorial responsivo;
- conversão direta pelo WhatsApp, telefone, Instagram e localização;
- imagens convertidas para WebP, normalizadas e otimizadas;
- metadados de SEO, Open Graph e schema.org de negócio local;
- suporte a `prefers-reduced-motion`;
- Vercel Analytics instalado e renderizado no layout raiz.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Verificação

```bash
npm run lint
npm run build
```

## Publicar na Vercel

1. Importe a pasta deste projeto na Vercel.
2. Mantenha o preset **Next.js** e os comandos padrão.
3. Defina `NEXT_PUBLIC_SITE_URL` com a URL final do site ou domínio.
4. Faça o deploy. O componente `Analytics` já está instalado e ativo; os dados aparecem no painel da Vercel após a publicação e o primeiro tráfego.
